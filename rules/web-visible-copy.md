# 网页与录制可见文案规则（2026-09-23）

来源：用户明确要求 web 和视频不出现“模拟、虚拟、工程样本、模拟数据”等表述，数据来源与限制“留在readme文件就可以了”，并要求写入新规则。该规则适用于当前恢复批次及以后明确启动的批次。

- 全部网页及视频画面不能出现“模拟、虚拟、仿真、物理仿真、工程样本、工程示例、模拟数据、工程样本模拟数据、演示数据、推演数据、合成数据”等标签，也不能改成 mock、dummy、synthetic、simulated、simulation、virtual、demo data 等英文替代。既有“专利、权利要求、权要”禁词保持生效。
- 覆盖导航、首页、页脚、表格内容、状态标签、图表文字、说明弹窗、悬浮提示、详情、搜索/筛选结果、空状态、加载状态、消息提示及后端返回到页面的文字。图表按钮打开的说明也是网页可见内容；不能只清理首页或只为了录制临时隐藏文字。真实错误要修复，不能隐瞒计算缺失。
- 数据来源、工程计算/演算性质、尚未验证的模型训练/设备接入/实测范围、部署限制，集中准确写入案件根目录 README.md，并随成品交付。网页采用准确、中性的业务字段名；不得改称“实测”“真实采集”“已接入设备”或声称未完成的训练已完成。原件、原文件名及原始证据不能因扫词修改；内部追溯元数据继续保留，README 是供人阅读的统一说明入口。
- Sol 建设和返修后用真实浏览器逐路由、逐关键交互采集可见文字与同状态截图；不扫描整个项目把 README、原件、日志和第三方依赖当网页问题。录制前先清理、排演；界面更新后重出截图与受影响视频，旧视频不能沿用。记录实际检查结果，不填写空白文字绕过。
- evidence/artifact-manifest.json 增加 readme="README.md"、ui_text_audit="evidence/ui-visible-text.json"。文字记录由实际浏览器采集，不从源代码或预期值代填。ui-visible-text.json 格式：{"rules_version":"2026-09-23","pages":[{"url":"http://127.0.0.1:本案端口/业务路由","state":"列表/详情/图表说明等实际状态","visible_text":"该状态实际可见文字，含图表、提示与必要标题","screenshot":"evidence/ui/对应状态.png","screenshot_sha256":"同状态截图实际SHA256"}]}。pages 覆盖 manifest 的全部 ui_screenshots，每次截图改变同步重采文字和哈希。Canvas/SVG 图中文字无法从DOM读取时，结合真实截图人工补录并记录检查方法。
- 父执行器检查记录完整性、截图哈希、文字禁词；该检查不能证明截图/OCR真实无漏。独立验收者 必须对照真实截图、图表说明及最终视频完整采样时间线和关键原帧验收；任何可见禁词属于 major，交回 Sol 清理并按影响重新录制，不能通过删除证据、伪造文字记录或降低抽样率放行。独立验收者 只审查，不自行改代码。
