# 系统深化与数据

本文件全部要求用于以后每个授权案件，测试案修改没有单案豁免。字段、算法及业务动作按本案定义适配，不照搬上一案名称。

## 系统需要做厚的部分

先盘点已有实现与原定义，列出每个核心业务动作、算法入口、输入边界、落库表、页面、导出和验证命令。复用有效计算与图文；发现当前图文与算法不一致，定位修复并重验受影响部分。

算法增强应解决本项目的问题：数据校验、量纲及边界、缺测/异常处理、关键约束、参数配置、状态转换、批量计算、历史追溯、性能和稳定性。需要优化/预测时实现实际求解或推断与可核对的基线，不用硬编码结论或没有调用者的“算法大全”凑代码。物理量按领域机理计算，业务类项目按可解释事件、约束和流程计算，不强套无关物理模型。

Web 以案件用户的工作过程组织，所有导航和按钮均有实际业务内容或清楚的合法不可用状态；不能用空页面、装饰按钮或弹出“成功”代替执行。常见模块可包含对象档案、任务/计划、运行监控、事件处置、结果详情、历史记录、统计和参数管理，按项目取舍，不机械凑页数。工业类使用对应工业控制界面，调度、医疗、监测等按各自对象设计。

中文标签与完整中文错误提示；仅保留单位、型号、通行缩写等必要英文，不展示技术术语堆砌、推导或内部流程。数据密度与层次并重：可筛选表格、排序分页、对象联动、详情抽屉、表单校验、提交反馈、状态流转、历史追踪、图例/时段交互和可下载导出。刷新与服务重启后保存结果仍存在。并发点击、空结果、网络失败、权限不足有真实处理，不吞错。

通用业务状态验收：任何创建、提交、调整或状态动作成功后，按本案实际可见项检查列表、详情、统计、摘要和日志引用同一对象和计算/业务版本；不能仅更新抽屉而背景保留旧状态。重取数据保留用户当前筛选、排序及仍合法的分页，越界页合理回退；关闭抽屉后用请求序号/取消等机制阻止迟到响应重新打开，连续点击及正反切换也实际测试。无对应界面项的项目如实记录不适用，不为凑该检查扩建无关业务模块。

交付源码包含配置范例、锁文件、数据库初始化/迁移、启动与停止入口、生产构建、健康检查和实际可用备份恢复脚本；使用/运行/安装/部署说明及日志留内部工作区，不放ZIP。按用途实施认证授权、密码安全存储、服务端校验、参数化数据库操作和密钥外置。不要预置可公开使用的固定管理员口令。实际验证本机部署条件；没有目标主机、域名等时记录待部署，不擅自上线。

## 开源检索与足量数据

先检索同领域开源仓库及仓库指向的正式数据集，至少核对一个实际适用且可取得的数据入口；尽量比较两种来源的适用性。保存 URL、仓库版本、访问时间、许可、下载文件哈希、字段/单位、筛选范围与适配决定。只有搜到介绍页不算取得原始数据。无法取得时如实记录具体检索与限制，使用本项目定义完成可复现计算，不捏造引用或下载成功。

在内部 `data-plan.json` 明确实体数、时间范围、采样间隔、关键事件与边界工况、预计行数、表间关系和验收指标。高频时序项目可从 30–90 天、多对象、十万行级计划；业务记录项目可从万行级主/明细与关联事件计划。它们是体量起点，最终规模由领域粒度、运行时长与硬件确定；合理较小规模要解释，禁止复制行、独立随机列、无物理关系或不可能频率凑量。

计算保留种子或确定性配置、参数、机理约束、扰动与运行日志；检验范围、分布、相关性、时序连续性、守恒/约束、主外键、重复、缺失和异常占比。训练类任务按时间或实体隔离划分，防止泄漏。所有字段具备类型、单位和业务含义。公共数据用于校准范围与分布，不改变其出处，更不能把扩充结果称现场实测。

## 重要 CSV 选择和清洗

重要性按用途选：业务实体、主时序/记录、事件、关键算法结果和必要汇总。排除调试转储、重复备份、可重建的中间宽表、分片重复和空 CSV。选择写入明确白名单，每项给出用途、主键、最少行数和重要性理由；不递归复制所有 CSV。

数据目录仅交付 CSV，UTF-8 BOM，保留字段顺序、数值精度、时间戳、标识、空值与原行序。整列剔除“生成数据”“数据来源”以及工具明列的同义元数据；其他列不得猜测删除。“生成时间”等业务列不自动去掉。剔除指定列后若值或文件名仍有禁词，报告行列定位，先按语义修复再导出，不把业务值自动删改。输入文件不修改，清洗记录和出处保存工作区。

代码和 Web 同样禁止用户列出的中文词；程序结构、数字运算、必要英文标识不受中文文案检查误伤。新编写的代码注释和字符串也要检查，不通过 Unicode 转义或拼接藏词。第三方必须保留的许可证文本集中放源码包的 `LICENSES`，单独核对法律保留，不删署名。原 Word 不做禁词替换；固定成品容器目录 `模拟系统` 仅名称豁免。

源码通过显式白名单压成成品 `模拟系统/项目源码.zip`，不直接复制整座工作区。排除所有层级、任何大小写的 README 与变体，以及针对原技术文档的解析、抽取、公式登记、原文映射、分析报告、解压媒体目录。业务系统自身需要的文件导入/解析模块应保留，不把所有名叫 parser 的业务代码一概删除；遇不明确文件，核对用途后加入排除表。源码包必须能从清洗后的外部 CSV 初始化数据，不能暗中依赖被排除的技术材料或旧工作区绝对路径。原工作区被排除文件完整保留。

源码ZIP内不放使用/运行说明、制作过程、原件解析和数据构造/来源说明，也不放揭示模拟性质的文案。内部README与数据出处如实保留数据性质、计算扩展过程、假设和未验证范围，不因排除交付说明删除证据或改称实测。必要第三方署名/入口/DOI/许可URL及变更指示集中许可证，法律必要内容保留；非必要制作用语也走语义审查，LICENSES不能作全文件藏说明豁免。不在每行CSV重复性质列，不在界面堆标签。
